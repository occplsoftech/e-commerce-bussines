Courier partner logos. To show an official logo, drop `<provider code in lower case>.svg` (or .png) here — e.g.
`delhivery.svg`, `shiprocket.svg`, `occpl_network.svg`, `bluedart.svg`, `ekart.svg` — and add the code and file name to
`LOGO_FILES` in `src/app/shared/components/courier-logo.ts`. Use only logos you are licensed to display.
Without a file the portal shows a coloured monogram badge.
